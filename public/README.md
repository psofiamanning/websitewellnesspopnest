# Archivos estáticos (raíz del sitio)

Los archivos en esta carpeta se copian a la raíz de `dist` al hacer `npm run build`.

## Para SEO y redes sociales

- **og-image.png** – Imagen para Open Graph y Twitter Card (recomendado 1200×630 px).  
  Si no existe, las redes usarán su propia vista previa. Añade aquí tu imagen para que los enlaces a popnest.app se vean con foto del estudio.
